# 星消乐（Gemz）

![CI](https://github.com/qianci2/team/actions/workflows/ci.yml/badge.svg)

轻量级益智消除类网页游戏：8×8 棋盘、5 种颜色、30 个关卡，纯浏览器运行，进度保存在本地，排行榜可选。

> **当前状态：P0–P3 领域逻辑已完成，尚无可游玩界面。** 已实现 M11 关卡配置与校验、M1 棋盘引擎、M2 计分、M3 关卡流程、M4 经济与生命，配套 85 项单元测试；界面与存档分别在 P4/P5 实现。设计基线中的模块接口已按 §6 落地，但尚不能通过浏览器完整游玩。

## 项目目标

- 免安装：打开网页即可游玩；
- 规则完整：交换消除、连锁、炸弹/彩虹、关卡目标、星级、道具、金币、生命值；
- 可离线：无网络也能完成单机流程，排行榜不可用时自动降级；
- 可验证：领域逻辑为纯函数，配套单元测试，并与需求编号逐条对应。

## 快速开始

当前仓库包含工程骨架、平台工具与 P1–P3 的领域逻辑，可运行：

```bash
npm run check   # 校验仓库结构、基线文档与核心文件
npm test        # 运行领域逻辑、平台工具与开发服务器测试
npm run dev     # 启动开发服务器：http://127.0.0.1:5173
```

状态页会显示平台工具自检结果；领域层目前通过 Node 单测验证，浏览器界面将在 P4–P6 接入。在 P5/P6 完成前，不声称提供可游玩版本。

已实现的规则与需求对应：

| 模块 | 内容 | 需求/规则 |
| --- | --- | --- |
| M11 | 30 关配置、逐条校验、内置默认回落 | FR-07、FR-10、FM-12、BR-02~BR-04/BR-06/BR-07 |
| M1 | 8×8 生成、交换、匹配、消除、下落补充、连锁（≤8）、炸弹/彩虹、死局与洗牌 | FR-01~FR-06、BR-01/BR-10 |
| M2 | 得分构成、连锁系数、`S_MAX=3480`、总积分硬上限 | FR-04、FR-16、NFR-08 |
| M3 | 目标进度、立即结算、失败判定、道具效果与每关限用 | FR-07~FR-09、FR-22、BR-07 |
| M4 | 星级、金币首通/重玩、道具购买、生命恢复与补满 | FR-09~FR-11、FR-14、FR-23、BR-08/BR-09 |

存档读写（FR-12/FR-13/FR-15）属于 P4/M10，本阶段只产出可落盘的纯函数增量。

关卡字段、校验口径与星级阈值标定待办见 [`docs/levels.md`](docs/levels.md)。

## 协作方式

- 分支：`main`（发布）、`develop`（集成）、`feature/<模块>-<姓名缩写>`、`fix/<主题>-<缩写>`、`docs/<主题>-<缩写>`。
- 提交：Conventional Commits，例如 `feat(board): 实现三消检测与交换合法性判定`。
- 合并：功能分支 → `develop` 走 PR，至少 1 人评审、CI 通过；阶段结束 `develop` → `main` 发版。
- 保留历史：合并使用 merge commit，**不使用 squash**，确保每个人的提交都能在主线中看到。

完整规则见 [CONTRIBUTING.md](CONTRIBUTING.md)。
