# 星消乐（Gemz）

![CI](https://github.com/qianci2/team/actions/workflows/ci.yml/badge.svg)

轻量级益智消除类网页游戏：8×8 棋盘、5 种颜色、30 个关卡，纯浏览器运行，进度保存在本地，排行榜可选。

> **当前状态：P0 工程骨架（尚无游戏实现）。** 本仓库先建立工程结构与协作规范，再按 [`docs/roadmap.md`](docs/roadmap.md) 的 P0–P8 阶段从零实现。设计基线中的 `levels.json`、接口与模块均为设计定义，不代表已经实现。

## 项目目标

- 免安装：打开网页即可游玩；
- 规则完整：交换消除、连锁、炸弹/彩虹、关卡目标、星级、道具、金币、生命值；
- 可离线：无网络也能完成单机流程，排行榜不可用时自动降级；
- 可验证：领域逻辑为纯函数，配套单元测试，并与需求编号逐条对应。

## 快速开始

当前仓库只包含骨架与文档，可先运行校验和测试：

```bash
npm run check   # 校验仓库结构、基线文档与关键编号
npm test        # 运行单元测试
```

游戏运行命令将在 P0 完成后补充；在实现完成前，本仓库不声称提供可游玩版本。

## 协作方式

- 分支：`main`（发布）、`develop`（集成）、`feature/<模块>-<姓名缩写>`、`fix/<主题>-<缩写>`、`docs/<主题>-<缩写>`。
- 提交：Conventional Commits，例如 `feat(board): 实现三消检测与交换合法性判定`。
- 合并：功能分支 → `develop` 走 PR，至少 1 人评审、CI 通过；阶段结束 `develop` → `main` 发版。
- 保留历史：合并使用 merge commit，**不使用 squash**，确保每个人的提交都能在主线中看到。

完整规则见 [CONTRIBUTING.md](CONTRIBUTING.md)。
