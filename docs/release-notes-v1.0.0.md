# 星消乐 v1.0.0

发布日期：2026-11-01

## 亮点

- 8×8 三消、30 关、5 种星石、连锁/炸弹/彩虹/冰层/死局重排。
- 七个界面：主菜单、选关、对局、结算/失败弹窗、排行榜、个人面板、设置。
- 指针/触屏/键盘输入、0.3 格滑动、合成音效与静音、后台暂停、色觉辅助、减少动态效果。
- 本地存档、迁移、多标签页合并、导入导出、只读降级。
- 排行榜客户端 + 3s 超时降级 + 本地模拟榜单 + mock 契约；真实后端为可选组件。
- 30 关难度/星级已按普通玩家代理求解器 **200 次/关、共 6000 局**标定。

## 验证

- `npm run check`：81 个必需文件 / 3 组基线标记。
- `npm test`：151 个通过，0 失败；覆盖率行 93.75% / 分支 82.98% / 函数 95.35%。
- 三段通过率 **98.7% / 97.6% / 84.1%**；所有关卡 Wilson 95% 下限 ≥64.9%。
- 通关样本星级：1★ **14.7%** / 2★ **48.9%** / 3★ **36.4%**；最不利关卡 2★ **45%**。
- 浏览器验收：Windows + Microsoft Edge（headless Chromium），43 项交互 + 9 项性能/可见性探针。

## 运行

```bash
npm run dev
# http://127.0.0.1:5173
```

无需 `npm install`；零运行时依赖。

## 已知限制

- 真实手机、Safari/Firefox、5 人可用性、30 分钟浏览器长会话未在本机执行；不要把这些写成已通过。
- 排行榜没有真实 SQLite 服务，只有客户端 + mock 契约。
- I-22 的 16ms 合并写未实现；`gemz_diag_config` 尚未接入。
- UI-6 个人主页是排行榜页内的个人面板，不是独立场景。
