# 分层特效实验室（3 种候选）

打开：`npm run dev` → <http://127.0.0.1:5173/web/fx-lab.html>

这一个版本不是“单层 shader 几何图形”，而是在 8×8 棋盘上做分层演出：

1. **底层**：烟尘、环境光、棋盘压暗。
2. **中层**：引力轨道、冲击环。
3. **顶层**：花瓣、冰晶碎片、火花、闪烁高光。
4. **收尾**：闪白、轻微震动、余辉。

| 编号 | 名称 | 核心层次 | 适合事件 | 特点 |
| --- | --- | --- | --- | --- |
| 01 | 星爆 | 彩色花瓣 + 烟尘 + 碎片 + 双层环 | 炸弹、4 连、组合 | 像花一样展开，颜色取自棋盘 |
| 02 | 霜裂 | 霜痕 + 冰晶碎片 + 冷雾 + 霜花 | 冰层、双层冰 | 白蓝冰面，强调“裂开”而不是放电 |
| 03 | 引力 | 宝石轨道 + 拖尾 + 内爆 + 爆发 | 重排、彩虹、大结算 | 棋盘元素被吸入再炸开；前摇压到 0.65s |

## 设计取舍

- 不再用“亮线 + 圆环 + 矩形”作为主体；线只作为冰裂纹/轨道，主体是粒子、花瓣、碎片和光晕。
- 所有效果锚定在具体格子，棋盘仍在，解决“割裂感”。
- 颜色来自当前棋盘 5 种星石，而不是固定霓虹色。
- 可直接移植到 `src/ui/renderer.js` 的 Canvas 2D 管线；不新增依赖。
- 接入游戏时需要限制粒子数量、增加 `prefers-reduced-motion` 降级，并避免遮挡目标面板。

## 文件

- `web/fx-lab.html`：棋盘舞台、效果切换、自动循环。
- `web/fx-lab.js`：棋盘绘制、粒子/碎片/花瓣/引力系统。
