## 2. 场景与导航

| 界面 | 场景 | 入口 |
| --- | --- | --- |
| UI-1 主菜单 | `menu` | 初始页；“继续第 N 关”一次点击进入对局 |

| UI-3 对局 | `playing` | 选关卡片或“继续” |

## 3. 操作

### 3.1 指针与触屏

- 点击一颗星石：选中（高亮描边 + 放大 + 短音效）。
- 再点相邻星石：交换；不相邻则改选。
- 按住并滑动 ≥ 0.3 格：按主导轴交换。指针仍在起始格内也能触发，目标由位移方向决定（TC-30）。
- 锤子道具：点“锤子”进入瞄准，再点目标格；Esc/H 或再次点击退出。
- 画布 `touch-action: none`，避免触屏拖动页面；道具按钮触控高度实测 138px（≥44px）。

### 3.2 键盘

| 按键 | 行为 |
| --- | --- |
| `Tab` / `Shift+Tab` | 棋盘 → 道具 → 音效 → 目标与操作；弹窗内焦点循环 |
| `方向键` | 移动棋盘光标（边界钳制） |
| `空格` / `回车` | 选定、与相邻格交换、确认锤子目标 |
| `Esc` | 取消选择 / 退出锤子 / 关闭帮助；选关、排行榜、设置页返回主菜单 |
| `H` | 进入/退出锤子瞄准（棋盘聚焦时） |
| `M` | 全局静音切换 |
| `P` / `?` | 打开“目标与操作”面板 |

焦点始终可见（3px 墨色描边、3px 偏移）。弹窗打开时焦点落到第一个动作按钮，关闭后回到原焦点。

## 4. 渲染与动画

- 8×8 Canvas 2D；纸面棋盘、土色星石、双层冰、炸弹/彩虹、选中环、键盘角标、拖拽箭头、Combo 文本与轻量粒子。
- 每颗星石有确定性的轻微旋转/位移抖动（由 `tile.id` 哈希），不是每次重绘随机。
- `renderer.play(steps, targetBoard, move)` 先应用本步交换，再按 `CascadeStep` 逐步清除/下落/补充；整段动画上限约 1.7s，给 M5 的 2.4s 兜底留余量。
- 动画结束后以 M5 的最终棋盘为准同步，动画不参与计分。
- `prefers-reduced-motion` 下立即应用全部步骤、关闭粒子和回弹。
- 空闲时不重绘；`ResizeObserver` 处理视口变化。`?debug=1` 在右下角显示 FPS。

## 5. 音频

- 首次用户操作（指针或键盘）惰性创建 `AudioContext`，页面加载时不出声。
- 5 类合成音效：`clear`（随连锁升半音）、`swap`、`item`、`win`、`fail`；另有一段低频背景铺底。
- 静音写入 DS-1 `muted`，立即生效并跨刷新保留。
- `visibilitychange` 隐藏时挂起音频上下文，恢复时继续（FR-27）。
- 上下文不可用时抛出一次，由 M5 捕获并显示“音频不可用，已静音运行”（FM-09）。

## 6. 无障碍

| 项目 | 实现 | 证据 |
| --- | --- | --- |
| 对比度 | 文字组合 ≥4.5:1、星石图形 ≥3:1；`auditContrast()` 在单测中逐条断言 | `test/ui.test.mjs` |
| 色觉辅助 | 5 种星石绑定唯一形状（圆/方/三角/菱形/星），开启后高对比绘制；颜色与形状双通道 | `palette.js`、设置页开关、窄屏截图 |
| 键盘可达 | 仅用键盘可完成：进入关卡 → 移动/选定/交换 → 道具 → 结算动作 | 浏览器验收 43 项含键盘路径 |
| 焦点可见 | 全局 `:focus-visible` 3px 描边；弹窗焦点陷阱与恢复 | `app.js` |
| 动效容忍 | 输入在动画期由 M5 排队；动画 ≤1.7s；减少动态效果立即收尾 | `session.test`、浏览器探针 |
| 文本可读 | 最小字号 12px；提示为完整句子；错误说明“还差多少” | 布局审计 360–1440px |
| 目标尺寸 | 按钮 ≥44px；道具按钮窄屏 138px 高 | 浏览器探针 |

Canvas 使用 `role="application"` + `aria-describedby` 说明；棋盘 `aria-label` 随光标更新（行列、星石名、冰层）；`aria-live="polite"` 播报选择、交换、无效交换、排队与结算。装饰形状全部 `aria-hidden`。

## 7. 状态、提示与降级

- 存档只读：顶部常驻提示条“当前浏览器环境无法保存进度……”，对局继续。
- 排行榜不可用：榜单页标注“本地模拟数据 · 离线降级”，并显示“网络不可用，排行榜暂不可用，单机游玩不受影响”；仍可查看 100 条确定性模拟数据与自己的名次。
- 无可消除组合：自动重排时显示“无可消除组合，已自动重排”。
- 无效交换：棋盘回弹 + 提示音 + 播报，不扣步数。
- 金币不足：小铺按钮置灰并显示“还差 N 金币”，不扣金币。
- 外标签页更新：M5 的 `save:external` 提示透传为浮动提示，不中断对局。
- 首次进入对局：不超过两行的引导条，可关闭且不再出现（localStorage `gemz.ui.tutorialDismissed`）。

## 8. 响应式

断点按设计 §8.5：

- ≥1100px：目标 / 棋盘 / 道具三栏；排行榜与个人主页双栏。
- 1000–1100px：对局改为单列，目标与道具横排。
- ≤700px：开场、阅读区、步骤、排行榜、设置全部堆叠；进度格两列；关卡两列；页脚链接两列；移除斜置纸片。
- 360–1440px × 五个界面全部实测无横向滚动、无文字截断（仅视觉隐藏说明与原生复选框尺寸被脚本误报）。

## 9. 与 M5 的契约

`presentation` 由 `web/app.js` 注入，P6 契约见 [session.md](session.md)：

```js
{
  onScene(scene),                    // 切页与棋盘同步
  play(events, meta),                // 返回 Promise；meta 携带本步 move/item
  audio(effect, chain),              // clear/swap/item/win/fail
  visibility(hidden),                // 音频挂起/恢复
  tick(now)                          // 兜底与定时器
}
```

P5 对 P6 的唯一扩展：`play` 的第二个参数 `meta`（只读）。M1/M3 的 `CascadeStep` 建立在交换后的棋盘上；没有 `move` 时，M6 无法从交换前棋盘正确回放。旧表现层忽略第二个参数即可兼容。

## 11. 已知限制

1. **UI-6 不是独立场景**：M5 场景集没有 `profile`，因此作为排行榜页的个人面板；入口仍为 1 次点击。
2. **没有真实后端**：排行榜只验证客户端、降级与 mock 契约；控制台的 `/api/rank`、`/api/score` 404 是预期。
3. **字体不打包**：按离线与体积约束只用系统字体回退；安装 Source Serif 4 / Instrument Sans 时观感更接近设计令牌。
4. **没有照片素材**：设计系统建议真实材料摄影，但项目要求素材自制/CC0 且零外部依赖，因此用程序化形状与 Canvas 星石替代。
5. **性能只在 headless Edge 采样**：真实手机、Safari/Firefox、5 人可用性测试仍属 P7/P8。
6. **难度与星级标定未执行**：`starKeep` 仍是设计预置值（TC-39/TC-40）。
7. **深链 `?level=N` / `?scene=`** 是演示与截图便利，仍经过 M5 的解锁/生命/配置校验。
