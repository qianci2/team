# 特效试验台（6 种 WebGL 效果）

打开：

```bash
npm run dev
# http://127.0.0.1:5173/web/fx-demo.html
```

操作：点击画布在指针处触发；数字键 `1–6` 切换；空格重放。所有效果是单个 WebGL fragment shader，零外部依赖。

| 编号 | 名称 | 视觉方向 | 适合的游戏事件 |
| --- | --- | --- | --- |
| 01 | 冲击波 | 中心闪光、环形波、放射条纹、星空 | 炸弹爆炸、组合触发 |
| 02 | 棱镜 | 彩虹旋臂、色相环、粒子闪点 | 彩虹消除、高连锁 |
| 03 | 漩涡 | 吸积盘、螺旋尘埃、青紫光带 | 重排、彩虹吸色 |
| 04 | 冰晶 | 霜纹、六角冰晶、放射冰刺 | 冰层破碎、双层冰 |
| 05 | 新星 | 白热核心、双层冲击环、放射光线 | 4 连炸弹生成、Boss 感结算 |
| 06 | 电弧 | 分叉闪电、紫蓝电弧、环形余波 | 连锁 3+、特殊元素连锁 |

## 选择建议

- 想“高级但不花”：**01 冲击波 + 06 电弧**，一个负责爆炸，一个负责连锁。
- 想突出彩虹：**02 棱镜**；想突出冰层：**04 冰晶**。
- 想做大结算：**05 新星**。
- 这些效果目前是独立 demo，未接入游戏；选定后再移植到 `src/ui/renderer.js`，并保留 `prefers-reduced-motion` 降级。

## 文件

- `web/fx-demo.html`：舞台、按钮、说明。
- `web/fx-demo.js`：WebGL 初始化、6 个 shader 分支、指针/键盘交互。
