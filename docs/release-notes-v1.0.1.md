# 星消乐 v1.0.1

发布日期：2026-11-01

## 本次修改

- **导航**：主菜单的关卡/排行榜/个人主页/设置改为整行 4 等分导航；对局左上角新增“菜单”，可确认退出本局返回主菜单，取消则保留对局。
- **文案**：去掉“把散落的星石”“每一关，只盯三件小事”“目标不多”“三个动作”等模板化文案，改为“交换星石，完成关卡目标”“通关要求”“玩法说明”等直接说明。
- **HUD**：得分/步数改为独立卡片；数字统一为无衬线等宽数字，不再一大一小；得分用暖色底强调。
- **冰层**：浅蓝冰面 + 深蓝描边 + 六角雪花 + 双层“2”角标，远距离可辨。
- **特殊元素**：炸弹/彩虹增加脉冲光环；生成或触发时增加扩散冲击环、全屏闪白与轻微震动；`prefers-reduced-motion` 下关闭。
- **图标**：新增菜单、得分、步数、星、冰、重排、锤子、加步等内联 SVG 图标。
- **配色**：底色、纸面与陶土/苔色块整体提亮。

## 验证

- `npm run check`：11 个必需文件 / 3 组基线标记
- `npm test`：152 个通过，0 失败
- headless Edge 720×1210 与 360×100 实际截图验证：导航、HUD、冰层、对局菜单正常，无横向滚动
