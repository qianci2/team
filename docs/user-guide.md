# 用户手册（v1.0.0）

《星消乐》是纯浏览器运行的 8×8 三消游戏：30 关、5 种星石、五种界面场景，进度保存在本机。

## 1. 启动

```bash
npm run dev
```

打开 <http://127.0.0.1:5173>。无需 `npm install`，项目没有运行时依赖；Node 20+ 仅用于开发服务器与测试。

直接双击 `web/index.html` 不行：浏览器会拦截 ES Module 与关卡数据请求，必须通过开发服务器或任意静态服务器访问。

## 2. 一次对局

1. 主菜单点“继续第 N 关”或“选择关卡”。
2. 点击一颗星石选中，再点相邻星石交换；也可以按住星石向相邻方向滑动 ≥0.3 格。
3. 三个及以上同色星石横/竖连成一线即消除；上方下落、顶部补充，形成新三连会继续连锁。
4. 本关全部目标达成的那一手立即结算；步数耗尽且仍有目标未完成则失败。
5. 结算弹窗显示得分、星级、金币与“下一关/重玩/返回主菜单”。

失败只扣 1 点生命，不扣金币或道具。生命每 15 分钟恢复 1 点，上限 5；生命为 0 时可用 200 金币补满。

## 3. 目标

| 目标 | 说明 |
| --- | --- |
| 目标分 | 在步数用完前达到本关目标分 |
| 收集 | 消除指定颜色的星石，达到指定数量 |
| 冰层 | 消除冰层格上的星石，冰层减 1 层；双层冰需要消两次 |

三项目标可能组合出现；全部完成才通关。

## 4. 星级

星级只由**通关时剩余步数**决定：

- 剩余步数 ≥ `keep3`：3★
- 剩余步数 ≥ `keep2`：2★
- 否则：1★

每关阈值已由 200 次代理求解器标定，见 `docs/calibration.json`。重复通关取历史最高星；金币按本局星级与 `rewardPaidStars` 差额/折半结算。

## 5. 道具与金币

| 道具 | 价格 | 效果 |
| --- | ---: | --- |
| 重排 | 100 金币 | 重排棋盘，不消耗步数 |
| 锤子 | 200 金币 | 消除任意 1 格；有冰层时同手减 1 层 |
| +5 步 | 300 金币 | 当前关剩余步数 +5 |

每关每种道具限用 1 次；库存消耗会立即写盘。购买入口在设置页“小铺”。

## 6. 键盘与无障碍

| 按键 | 行为 |
| --- | --- |
| `Tab` / `Shift+Tab` | 在棋盘、道具、按钮间移动焦点 |
| 方向键 | 在棋盘内移动光标 |
| `空格` / `Enter` | 选定、交换、确认锤子目标 |
| `Esc` | 取消选择 / 退出锤子 / 关闭帮助 / 返回 |
| `H` | 进入/退出锤子瞄准 |
| `M` | 静音开关 |
| `P` / `?` | 打开目标与操作帮助 |

设置页可开启色觉辅助：5 种星石分别附加圆/方/三角/菱形/星形，颜色不再是唯一区分通道。开启“减少动态效果”后动画会快速收尾。

## 7. 排行榜

排行榜是可选功能：没有真实后端时自动显示**本地模拟数据**，并标注“本地模拟数据 · 离线降级”；单机流程不受影响。

- 昵称 3–12 个中英文、数字或下划线；非法昵称不能提交。
- 提交的是历史各关最高分之和（总积分）。
- 本版本不包含账号、云同步或真实排行榜服务。

## 8. 存档与导入导出

- 自动保存在浏览器 `localStorage` 的 `gemz_save_v1`。
- 设置页可导出 JSON、导入 JSON；导入前校验版本与字段类型，非法文件不会破坏当前存档。
- 隐私模式/配额满时进入只读模式：本局可继续，但关闭页面后可能丢失进度。
- 多个标签页会按 `updatedAt` 合并：星级/最高分/解锁取较大值，金币/道具/生命取较新一方。

## 9. 常见问题

| 现象 | 处理 |
| --- | --- |
| 打开页面空白/提示通过开发服务器打开 | 执行 `npm run dev`，用 <http://127.0.0.1:5173> 访问 |
| 排行榜显示“本地模拟数据” | 没有真实后端，属预期降级；单机不受影响 |
| 提示“当前浏览器环境无法保存进度” | 隐私模式/存储被禁用；换普通窗口或清理配额 |
| 页面没有声音 | 浏览器要求先点击/按键才能启用音频；检查静音开关 |
| 关卡数据异常 | 外部 `levels.json` 校验失败时回落到内置默认配置 |

## 10. 已知限制

- 真实排行榜服务、账号、云同步、跨设备进度不在本版本范围。
- 已在 Windows + Microsoft Edge（headless Chromium）验收；Safari/Firefox、真实手机触屏与 5 人可用性测试未在本机执行。
- 难度与星级基于普通玩家代理求解器标定，不等同于真实玩家样本。
- UI-6 个人主页是排行榜页内的面板，不是独立场景。
