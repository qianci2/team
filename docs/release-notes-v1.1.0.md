# 星消乐 v1.1.0

发布日期：2026-11-02

## 自 v1.0.1 以来的变化

### 对局表现

- 接入分层特效：4/5 连、炸弹/彩虹触发**星爆**；冰层破裂触发**霜裂**；彩虹或 4+ 连锁触发**引力**。
- 炸弹重绘为白热核心 + 旋转金色日珥 + 橙色外晕；彩虹重绘为五色棱镜核。
- 特殊元素**常态旋转/脉冲**，不再只在状态变化时重绘。
- Combo 改为大号倾斜横幅，缩放 + 全屏棋盘震动；震动幅度和时长随连锁增加，5+ 连锁深红强调并叠暖色闪光。

### 音效

- 全部改为 Web Audio API 实时合成，不再依赖采样文件：
  - 上升琶音、拍击、和弦闪光、五声音阶风铃、低音冲击、玻璃碎响、钟琴分音。
  - 每段连锁单独触发风铃，音高随连锁上行；冰层碎裂触发玻璃碎响。
  - 所有声音经过 `DynamicsCompressor` 防爆音。

### 排行榜

- 初始为空榜，不再生成虚构玩家。
- 只有成功提交成绩后才显示自己的本机记录；提交后自动刷新榜单。
- 空榜和离线状态文案更新。

### 其他

- 主菜单整行 4 等分导航、对局“菜单”退出确认、HUD 数字统一、冰层雪花与双层角标、内联 SVG 图标、整体配色提亮（v1.0.1 已包含）。
- 新增 `docs/fx-demo.md`、`docs/fx-lab.md` 记录特效试验台与设计取舍。

## 验证

- `npm run check`：91 个必需文件 / 3 组基线标记
- `npm test`：156 个通过，0 失败
- headless Edge 720×1280 / 360×800：导航、空榜、Combo、特殊元素、对局菜单实测
- 浏览器真实点击解锁后：6 类合成音效调用无异常

## 已知限制

- 真实手机、Safari/Firefox、5 人可用性、30 分钟浏览器长会话仍未在本机执行。
- 排行榜仍只有客户端 + mock 契约，没有部署真实 SQLite 服务。
- `docs/screenshots/` 的 P5 截图采集于 2026-10-26，当前界面以代码和 `docs/ui.md` 为准。
